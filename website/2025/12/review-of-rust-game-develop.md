# 《Rust 游戏开发实战》读后感

书籍的 ISBN：975-7-115-62660-8。

## 读后感

本书介绍了 Rust 语言的基础语法知识，基于 bracket-lib 框架实现了一个地下城探险类游戏，并介绍了游戏设计的一些技巧。

## 一些有意思的地方

这里介绍了一些这本书的有意思之处。

### 渐进式开发

本书先构建一个 Flappy Dragon 游戏，初步介绍了 Rust 和 bracket-lib。

接着，再进行地下城探险游戏的开发，先开发简单的游戏原型，再逐步添加新功能。

且章节之间较为独立，一个章节专注于开发一个部分，安排较为合理。

### 丰富的内容与解决实际问题

每个新章节都伴随一个情景引入，语言较为有趣。

同时，一些游戏开发的相关知识也能给予人很大启发，如元胞自动机和醉鬼的脚步这两种地图生成算法。

## 一些神秘的地方

这里介绍了一些这本书比较神秘的部分。

### 图像字体

bracket-lib 可以让你假设在一个 80*50 的终端下开发，且允许你通过图像字体来显示图像。

这种方案在某种程度上是简洁的，但也在一定程度上引入了新的问题。

我认为这是在便于开发与教学和游戏引擎的表现力之间的一种取舍。

## 一些吐槽的地方

这里只是一些吐槽。

### 代码风格

平心而论，作者的代码风格并不差，只是偶尔会用几个 clone 来绕过借用检查，或者在闭包中写很多内容而不拆成函数。这对于游戏开发来说够用。

但有时免不了被我吹毛求疵一下💦。

### 游戏引擎的选择

本书使用 bracket-lib crate 作为游戏引擎，用 legion crate 提供 ECS 功能。

这两者的开发并不积极，所以目前这两者仅适合用于充当教学案例，并不适合继续学习。

### 代码说明

这本书对于代码会进行较多的说明，这是一个好事。

但是作者还是缺了部分说明，导致阅读时可能令人疑惑，这些内容可能涉及内部实现。

比如，文中通过构建一个搜索步数为 1024 的 Dijkstra 地图来获取所有距离超过 2000 的地块坐标，目的是识别地图中所有不可达的地块，但并未解释为何该方法是正确的。实际上，在查看内部实现细节后发现，所有地块的初始值被设为 f32::MAX，而文中同样也未提及这一点。

### 翻译

这本书的翻译其实不错，且在一些时候会加入一些译者的注释，帮助读者理解，这是如此的好以至于我不容易遇到翻译腔。
